# U-Build — Regression Checklist (Этап 0 / Baseline)

Чеклист фиксирует текущее поведение. Каждый пункт должен проходить до начала архитектурных изменений и после каждого этапа миграции. При провале — этап считается незавершённым.

**Формат проверки:**

`[ ]` не проверено · `[x]` проходит · `[!]` сломано · (screenshot / note)

## Как использовать

1. **Этап 0** — пройти весь чеклист на текущем `main`, зафиксировать commit + (по возможности) screenshots ключевых состояний.
2. После каждого этапа Roadmap — прогнать релевантные разделы (минимум 1–9 + 12).
3. Любой `[!]` блокирует переход к следующему этапу.
4. Новые фичи (dynamic lighting, seasons) добавляются отдельными пунктами после Этапа 4–5, а не в этот baseline-чеклист.
